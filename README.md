# Estudos-com-Phyton
Compartilho aqui alguns dos meus aprendizados na área de programação

Atualmente criei um mini sistema de checklist para reforçar meus conhecimentos 

A primeira versão do sistema possuia apenas funcionalidades como:
- Adicionar tarefas
- Listar tarefas
- Remover tarefas

Já na segunda versão apenas corrigi alguns bugs e validações, além de refatorar o código adcionando match case no lugar das estruturas de repetições, e as funcionalidades ficaram em funções
